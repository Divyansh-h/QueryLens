# Domain & Cloudflare Setup Guide

This guide walks through configuring your newly registered domain with Cloudflare for the main SEO website (hosted on a VPS) and routing the `app` subdomain to the QueryLens Render service.

> **Note:** Replace `[DOMAIN]` with your actual domain name (e.g., `querylens.dev`) and `[VPS_IP]` with the IP address of your SEO/marketing website server.

---

## Phase 1: Cloudflare Onboarding & DNS

### 1. Change Registrar Nameservers
1. Log in to your domain registrar (Namecheap, GoDaddy, Google Domains, etc.).
2. Find the **DNS Settings** or **Nameserver** management page for `[DOMAIN]`.
3. Select **Custom Nameservers**.
4. Log in to Cloudflare, click **Add Site**, and enter `[DOMAIN]`. Select the Free plan.
5. Cloudflare will scan existing records. Click Continue.
6. Cloudflare will provide two nameservers (e.g., `liz.ns.cloudflare.com` and `jack.ns.cloudflare.com`).
7. Copy these into your registrar and save.
8. In Cloudflare, click **Done, check nameservers**. (This can take anywhere from 5 minutes to 24 hours to propagate).

*📸 **Screenshot Idea**: The registrar's custom nameserver input fields.*

### 2. Configure DNS Records for the Main Site
Once Cloudflare is active for the domain, navigate to the **DNS > Records** tab on the left sidebar.

1. **Add the Root A Record (SEO Website):**
   * **Type**: `A`
   * **Name**: `@` (represents the root domain)
   * **IPv4 address**: `[VPS_IP]`
   * **Proxy status**: Proxied (Orange Cloud)
   * Click **Save**.

2. **Add the WWW CNAME Record:**
   * **Type**: `CNAME`
   * **Name**: `www`
   * **Target**: `[DOMAIN]`
   * **Proxy status**: Proxied (Orange Cloud)
   * Click **Save**.

*📸 **Screenshot Idea**: The Cloudflare DNS record table showing the `A` and `CNAME` records with the orange "Proxied" clouds.*

## Phase 2: Render Subdomain Setup

We need to point `app.[DOMAIN]` to the existing Render backend/frontend service.

### 1. Cloudflare DNS for Render
1. In the Cloudflare **DNS > Records** tab, click **Add record**.
2. **Type**: `CNAME`
3. **Name**: `app`
4. **Target**: `querylens-xodd.onrender.com` (Your Render assigned `.onrender.com` URL)
5. **Proxy status**: **DNS Only** (Gray Cloud) — *Crucial: Render handles its own SSL certificates via Let's Encrypt. Proxying this through Cloudflare initially can prevent Render from verifying domain ownership.*
6. Click **Save**.

### 2. Render Custom Domain Configuration
1. Log in to the Render Dashboard and click on your `querylens` Web Service.
2. Go to the **Settings** tab.
3. Scroll down to the **Custom Domains** section.
4. Click **Add Custom Domain**.
5. Enter `app.[DOMAIN]` and click **Save**.
6. Render will verify the DNS record. Since we set it to "DNS Only" in Cloudflare, it should verify successfully and provision a TLS certificate within a few minutes.

*📸 **Screenshot Idea**: The Render "Custom Domains" section showing `app.[DOMAIN]` with the green "Verified" badge.*

---

## Phase 3: Cloudflare Security & Performance

Now, configure Cloudflare to secure the main website and optimize delivery.

### 1. SSL/TLS Settings
1. Go to **SSL/TLS > Overview** in the left sidebar.
2. Set the encryption mode to **Full (Strict)**. 
   *(Note: Your VPS must have a valid origin SSL certificate configured, such as one generated by Certbot/Let's Encrypt, or a Cloudflare Origin CA certificate).*
3. Go to **SSL/TLS > Edge Certificates**.
4. Enable **Always Use HTTPS** (forces all HTTP traffic to redirect to HTTPS).
5. Enable **Automatic HTTPS Rewrites**.

*📸 **Screenshot Idea**: The SSL/TLS Overview page with the "Full (Strict)" radio button selected.*

### 2. Performance (Caching & Minification)
1. Go to **Speed > Optimization** in the left sidebar.
2. Under **Auto Minify**, check the boxes for:
   * **JavaScript**
   * **CSS**
   * **HTML**
3. Go to **Caching > Configuration**.
4. Ensure **Browser Cache TTL** is set to at least **4 hours** (or 1 year for static assets if you handle cache busting in your web framework).
5. Ensure **Caching Level** is set to **Standard**.

*📸 **Screenshot Idea**: The Auto Minify checkboxes fully selected.*
